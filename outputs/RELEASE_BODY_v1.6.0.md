# X32 Remote v1.6.0

服务端规范 **v1.10** · 新增 **效果器全量标定**：从「只标定 5 种混响」扩到 **61 种算法 / 886 个参数**；
顺带修掉一个**三端各自都写错过**的 FX 返回地址 bug（症状：推子拖得动、台子没反应）

## 重点

| # | 内容 |
|---|---|
| 1 | **效果器全量标定**：61 种算法 / 886 个参数 / 9 个分类；FX 5–8 只能装 34 种轻量算法（heavy 的 27 种仅 FX 1–4） |
| 2 | **参数面板按标定渲染**：数值带真实量程与单位（`2.50 s` / `120 ms` / `-3.5 dB`），枚举下拉显示中文选项，参数个数随算法变（4–64） |
| 3 | **修 FX 返回地址**：真台拼写是 `fxrtn`，此前模拟器/安卓写 `fxret`、iOS 写臆造的 `/rtn/fx/` —— 都是台子不理的地址 |
| 4 | **修正标定错误**：HALL 的 `par01` 是**预延迟(ms)**、`par02` 才是**混响时间(s)**，旧表搞反了（三端的「混响时间」滑杆其实一直在调预延迟） |
| 5 | **FX 槽名查询修复**：`/fx/<槽>/config/name` 早被服务端通用名称处理器拦掉，槽名一直是空的；现已放行并补满 8 个槽 |
| 6 | **回归网不再绑死 10023**：Python 全套 **13/13 组通过**（首次完整绿） |

## 三端都能做什么

- **选算法**：下拉按 9 个分类分组，heavy 项标「仅 FX1-4」并本地拦截
- **调参数**：滑杆带量程与单位，枚举下拉中文选项；未设置的参数显示「未设置」，
  不拿 `0.0` 冒充（大量参数下限大于 0，拿 0 填会把滑杆骗到量程外）
- **效果开关 / 混合比 / FX 返回推子与静音**
- 参数中文名与量程不在 OSC 线路上：网页端由服务端下发，iOS / Android 走纯 OSC，
  随 App 带一份同源标定表（一次生成 JSON + Swift + Android assets，`--check` 防漂移）

## 已知限制

1. 服务端仍无鉴权（与真台 OSC 同一信任模型），演出网络建议单独 SSID
2. iOS 后台约 30 秒挂起，只能当前台遥控器
3. macOS / Windows 未签名，首次需右键打开
4. 网页试用版快照停留在 2026-10-18
5. 26 项参数出厂默认值仍待真机核对（`/api/info.calibration` 会列出）
