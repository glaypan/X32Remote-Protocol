# X32 Remote v1.3.1

服务端规范 **v1.7** · App 两端零代码改动（Android 1.1.0 / iOS 1.1.0，同源码重建）
上一版 v1.3.0 的增量：**给网页控制台补上扫码进入**。

## 重点

| # | 内容 |
|---|---|
| 1 | **扫码进入**：终端启动即打印二维码，网页「设置 → 手机/安卓平板连接」也有；手机扫一下直达控制台，不用手输 IP |
| 2 | **自研二维码编码器**（纯标准库）：字节模式 / 纠错 M / 版本 1–10，按 ISO 18004 选掩码；`/qr.svg` 只渲染地址、不请求它 |
| 3 | **修单文件形态缺陷**：`import x as y` 的别名在合成时被剥掉 → 单文件 `/qr.svg` NameError 500；合成工具已保留别名 |
| 4 | **回归 10 组**：新增 `qr` 组（把矩阵解回原文 + RS 校验位全零 + 翻转必失败） |

## 验证

回归 **10/10 组通过**；二维码另用 `python-qrcode` 做同版本同掩码逐位比对（5/5 一致，
该依赖只在开发环境）；390×844 截图核对；`/qr.svg` 反解矩阵与页面地址逐位一致。

## 已知限制

- 26 项出厂默认值待真机核对（`/api/info.calibration`）。
- 取点线上取值形式未真机验证（已双形式兼容）。
- iOS / Android 的 dB 文案仍是旧式（只影响显示）。
- 网页试用版为 2026-10-18 纯前端虚拟台快照，不含通道参数页签。
- 网页控制台**无鉴权**：同网段任何人可控制（与真台 OSC 同级信任模型）；二维码不含凭据。
