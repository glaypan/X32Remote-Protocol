# X32 Remote v1.3.0

服务端规范 **v1.7** · App 两端零代码改动（Android 1.1.0 / iOS 1.1.0，同源码重建）

本版把「十个旋钮」之外的通道参数补到 **75 项**、支持**按地址订阅**、修掉一个
隐藏已久的 **dB 曲线错误**，并清掉**五项 P0** 竞态与写风暴缺陷。

## 重点

| # | 内容 |
|---|---|
| 1 | **通道参数 75 项**：前置 7 / 插入 3 / 噪声门 11 / 动态 18 / 均衡 17 / 发送 3（二维 通道×Bus），`ch` 行 8→58 字段，四类面板全部可读写 |
| 2 | **`/subscribe` 按地址订阅**：首轮立即回值、50 ms 倍数、10 s 过期；修掉「后加入的订阅者收不到变化」（`PUSH_CACHE` 全局结构缺陷） |
| 3 | **枚举双形式**：真台回字符串（`"POST"`）不再被静默落回默认值——旧代码读一次就改值 |
| 4 | **电平 161 档**（`f=k/160`）+ **推子 dB 曲线改 4 段伪对数**（0.25 处旧式 −9.5 dB，真台 −30 dB，偏 20.5 dB） |
| 5 | **台面预设**（规范 v1.6）：可选范围快照 + 场景全局/局部 recall + 预设动作；partial **不发场景号**，找不到预设跳过、绝不退化全局 |
| 6 | **五项 P0**：卡片竞态（按代运行）、配置原子写（坏文件 `.corrupt-<时间戳>`）、写风暴合并器（20/50/100/250 ms）、渐变打断双拦截、recall 代号 |
| 7 | **模块化**：`x32sim/` 24 模块 + 合成单文件（8918 行）双形态，`check_layers` 无环，`dualform` 16 项差分 |
| 8 | **4G 流量实测 22.5 → 11.7 MB/h**：条件轮询 + gzip + CSP 只对 HTML + 后台降频 |

## 升级注意

- **dB 数值变化是修正**：`0.75→0`、`0.5→−10`、`0.25→−30`、`0.0625→−60`；下发值不受影响。
- 配置自动兼容，新增字段补默认；损坏文件备份后回落默认，不再静默吞掉。
- trim 默认 ±18 dB（旧固件 `--trim-range 12`），`/api/info.trimRange` 供前端同步滑块。
- `/api/state?v=<指纹>` 为新增可选项，不带仍收全量。

## 已知限制

- **26 项出厂默认值待真机核对**：`/api/info.calibration` 列出，`tools/verify_defaults.py` 一键比对。
- **取点线上取值形式**（索引 vs 字符串）未真机验证；已双形式兼容，`tools/probe_console.py` 可确认。
- iOS / Android 的 dB 文案仍为旧式（只影响显示），规范 v1.7 已标注迁移。
- 网页试用版是 2026-10-18 纯前端虚拟台快照，**不含本版新增的通道参数页签**。
