# X32 Remote v1.4.0

服务端规范 **v1.7** · 新增 **自动增益 / 自动推子（Vocal Rider 式）**，并接入 iOS / Android

## 重点

| # | 内容 |
|---|---|
| 1 | **自动增益 / 自动推子**：目标电平（默认 -18 dBFS），双执行器（推子 / 数字增益），三档速度，实时可调 |
| 2 | **目标曲线**（riding target）：时间-电平点列、可循环；网页上点/拖/双击即可编辑，主歌 -24、副歌 -16 |
| 3 | **侧链触发**：看另一路电平、修这一路（主持人说话 → 音乐自动让开） |
| 4 | **表源可切**：推子后（闭环）/ 推子前（开环，推子怎么动都不影响测量） |
| 5 | **平滑三件套**：功率平均 + 死区 + 速率限制（1.5/5/15 dB/s），不会一格一格地抽 |
| 6 | **iOS「自动」页签 + Android 菜单入口**：两端只做配置与显示，控制律在电脑端服务 |
| 7 | **电平模型重做**：信号源与推子位置拆开，避免自动推子自激塌陷 |

## 升级注意

- 无破坏性变更；`user_config.json` 新增 `rider` 键（缺省即不启用）。
- 单通道必须显式启用才会动作；总开关只控制整体。
- App 需重装才有自动入口（Android 1.2.0 / iOS 1.2.0）；网页端不受影响。

## 验证

回归 **11/11 组**，`rider` 组 **42 项**（收敛、单拍 ≤ 速率上限、死区停写、三档先后、
量程累计、静音冻结、双执行器、人工让位、曲线插值/循环/消毒、侧链、推子前/后、配置组合）。
桥接实证：A 桥接 B 后两边推子逐秒完全相同 → `source="auto"` 真下发。
`pyflakes` 净、`check_layers` 无环、单文件 26 模块与包同步。
