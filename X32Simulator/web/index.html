这套流程走标准 X32 OSC 指令,连真调音台同样适用。
自动增益 / 自动推子：把通道电平稳在目标值（默认 -18 dBFS），可以边演边调。 推子模式动的是推子（接真台时电动推子看得见它在走）；增益模式动数字增益，推子不动。
三档速度改的是「平均窗口 / 死区 / 每秒最大修正」——所以它不是每个字都拉一下，而是平滑地跟着走。
